description: Record a year's revenue and output (tonnes of product, units) so intensity can be worked out.
---

Read CLAUDE.md first.

```bash
npm run carbon -- set-inventory --inventory=FY2027 --revenue=67000000 --output=4800 --actor="<name>"
```

Revenue in dollars of the reporting entity.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
